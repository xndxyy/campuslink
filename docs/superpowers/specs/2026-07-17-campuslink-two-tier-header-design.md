# CampusLink 双排顶部导航设计

## 目标

将当前桌面端单排 Header 恢复为用户确认的双排布局，同时保留现有品牌、入口和中文文案。此次只调整全站顶部，不修改首页正文、业务路由或数据逻辑。

## 已确认布局

桌面端顶部由三部分组成：

1. 页面最上方保留深色细横条。
2. 第一排左侧显示校徽与“西大同学 CampusLink”，右侧显示绿色“发布内容”按钮。
3. 第二排左侧依次显示“学习资源、二手交易、校园工作、校园论坛”，右侧显示“我的发布、我的收藏”，两个导航组之间使用竖向分隔线。

第一排和第二排使用同一内容宽度与左右边界。绿色按钮保留深蓝描边与硬阴影，导航使用当前深蓝文字和绿色悬停状态。

## 响应式行为

- 桌面端完整显示两排结构，个人入口靠右对齐。
- 窄屏下第一排仍保留品牌与发布按钮，并缩小字号、图标和按钮尺寸。
- 第二排保持单行，必要时允许横向滚动，避免隐藏“我的发布”或“我的收藏”。
- 不使用文字缩放随视口变化，避免导航跳动或溢出。

## 代码边界

- `app/layout.tsx`：将 Header 内容组织为品牌操作层与导航层。
- `app/globals.css`：定义双排布局、共同内容宽度、分隔线和移动端规则。
- `components/brand/site-brand.tsx`：继续复用现有品牌组件，不修改品牌资产。

不新增组件或数据依赖；现有链接地址、ARIA 导航名称和跳转行为保持不变。
